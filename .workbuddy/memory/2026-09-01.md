## 导出功能两项修正（用户反馈）
1. 总计行原本只是写死的数字，改为真正的 Excel `SUM` 公式（`C{dim+2}` 单元格 `f:'SUM(C2:C{dim+1})'`）。注意：SheetJS 的 `aoa_to_sheet` 会把 `'=SUM()'` 当字符串存，必须手动写 cell 对象 `{f,t:'n',v}`；且**总计行必须放进 rows 数组内**（否则不在 `!ref` 范围不会被写出）。
2. 导出改为弹窗选择月份：点「导出 Excel」弹出按月列表（含该月净合计），点某月导出单 sheet；另有「导出全部月份」按钮。空月不出现在列表。
- 已用 node 验证：9 月样例 500-100+1200-300=1300，导出后 C32 为 `{"t":"n","v":1300,"f":"SUM(C2:C31)"}`。已 git 提交（5c45dbe）。
