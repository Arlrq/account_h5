## 记账本 H5（account_h5）
- 从用户提供的 `C:\Users\LRQ13\Desktop\account.xlsx`（每月一个 sheet：月份/天数/金额，行=1号..31号，末尾总计）出发，构建纯前端记账 H5。
- 技术：单页静态站，无后端；数据存 localStorage（key `account_records_v1`，记录 {id,date,amount,note,ts}，amount 为净收支，可负）。
- 功能：记一笔（日期+净金额+备注）、总余额+当月合计汇总、按月切换（上/下月/回到本月）、SVG 月度趋势图（正红负绿，遵循涨红跌绿）、导出多 sheet Excel（vendor/xlsx.full.min.js 本地化，无 CDN 依赖）。
- 部署目标：GitHub Pages。已 `git init` 并提交初始版本，README 含 Pages 部署步骤（未推送，需用户提供仓库）。
- 文件：index.html / css/style.css / js/app.js / vendor/xlsx.full.min.js / README.md / .nojekyll。
